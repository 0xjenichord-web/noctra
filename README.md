# NOCTRA

Independent security research and bug bounty intelligence project.

## Foundation

This initial foundation contains selected reusable NEA modules:
- Universal contracts
- Engine registry
- Universal orchestrator
- Control center
- Intelligent task router
- Verification
- Recovery store and restore coordinator

## Development principles

- Independent from NIMPI Wallet
- Incremental and test-driven development
- Read-only discovery by default
- Authorized security testing only
- Human review before vulnerability submission

## Deferred integrations

Adaptive Impact and Safety Recovery require independent
implementations before they can be integrated safely.
NIMPI-specific Audit Orchestrator integrations are excluded.
